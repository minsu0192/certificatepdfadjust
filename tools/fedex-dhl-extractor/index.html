PDF TO EXCEL

FedEx / DHL Extractor

FedEx Duty·Freight, DHL 마감 인보이스, DHL eTradebill PDF를 Excel 출력 구조로 정리하는 신규 도구입니다.

PDF는 브라우저 안에서만 처리되며 서버에 업로드되거나 저장되지 않습니다.
개발 준비 상태

현재 페이지에는 구현 범위와 검증 기준이 먼저 반영되어 있습니다. 실제 PDF 추출 기능은 이 기준으로 구현한 뒤 사용 가능 상태로 전환합니다.

01

문서 자동 분류

파일명과 PDF 본문을 함께 확인해 FedEx Freight, FedEx Duty, DHL 마감 인보이스, DHL eTradebill, 미확인 문서로 구분합니다.

02

브라우저 내부 처리

PDF.js 텍스트 추출을 우선 사용하고, 텍스트가 부족하거나 깨진 경우 필요한 페이지만 OCR 대상으로 분류합니다.

03

Excel 출력

File_Index, Invoice_Summary, Charge_Detail, Review 시트로 나누어 처리 결과와 검토 필요 항목을 함께 저장합니다.

04

정규화 및 검증

금액, 날짜, Invoice Number, AWB Number를 정규화하고 합계 불일치나 필수값 누락은 CHECK/ERROR로 표시합니다.

처리 흐름

업로드부터 Review까지

  1. PDF 추가FedEx와 DHL PDF를 섞어서 여러 개 업로드합니다.
  2. 중복 제거SHA-256 해시가 같은 파일은 최초 파일만 처리합니다.
  3. 텍스트 추출/OCRPDF 텍스트 레이어를 먼저 읽고 필요한 페이지만 OCR을 실행합니다.
  4. 검증문서별 합계 검증 후 OK, CHECK, ERROR 상태를 부여합니다.
  5. Excel 다운로드검토 대상은 Review 시트에 원인과 대상 식별자를 남깁니다.
Excel 시트

출력 구조

File_Index파일명, 해시, 문서 유형, 페이지 수, 중복 여부, 처리 상태
Invoice_SummaryFedEx, DHL 마감 인보이스, eTradebill 요약 정보
Charge_DetailFedEx 운송장별 charge와 DHL charge 상세 행
ReviewCHECK/ERROR 사유, 기대값, 추출값, 차이, 조치 내용
