라이브러리 로드 실패: 인터넷 연결을 확인하거나 페이지를 새로고침하세요.

편집 · 페이지 관리

순서를 바꾸고 필요한 페이지만 추출하세요. 텍스트와 서명도 추가할 수 있습니다.

PDF

PDF를 여기에 끌어다 놓으세요

또는 클릭해서 파일 선택 · 한 번에 PDF 한 개를 편집합니다.

PDF를 열면 페이지 미리보기가 표시됩니다. 새 파일을 열면 현재 편집 작업이 초기화됩니다.

페이지 정리

드래그 또는 ← → 버튼으로 순서를 바꿉니다. 체크한 페이지를 추출·회전·삭제할 수 있습니다.

텍스트를 입력한 뒤 페이지에서 원하는 위치를 클릭하세요. 추가 내용은 실행 취소로 되돌릴 수 있습니다.

텍스트는 한글을 포함해 이미지로 추가됩니다. 기존 문구는 흰색으로 가린 뒤 새 글자를 추가할 수 있습니다. 가리기는 원본 텍스트의 영구 삭제가 아니며, 기존 문장 자체를 직접 수정하지 않습니다.

PDF 합치기

파일을 추가하고 순서를 정하면 하나의 문서가 됩니다.

PDF

합칠 PDF 여러 개를 선택하세요

선택한 순서대로 하나의 PDF로 저장합니다.

    PDF → 이미지

    공유하기 쉬운 JPG, 선명한 PNG. 필요한 페이지만 골라 저장하세요.

    IMG

    이미지로 변환할 PDF를 놓아 주세요

    JPG 또는 PNG로 변환합니다. 페이지 범위를 지정할 수도 있습니다.

      이미지 형식 변환

      사진과 이미지를 필요한 형식으로. 여러 파일도 한 번에 변환하세요.

      IMG

      이미지를 여기에 끌어다 놓으세요

      PNG, JPG, WebP, GIF, BMP · 여러 파일 선택 가능

      한 파일은 이미지로, 여러 파일은 ZIP으로 저장합니다. 작은 이미지는 확대하지 않습니다. 움직이는 GIF·WebP는 첫 프레임만 저장하며, JPG는 투명 배경을 선택한 색으로 채웁니다. 메타데이터는 유지되지 않습니다.

        PDF 잠금 해제

        비밀번호가 있는 문서는 비밀번호를 입력해 잠금을 해제하세요.

        PDF

        잠금을 해제할 PDF를 여러 개 선택하세요

        텍스트와 화질을 유지하며 비밀번호 및 인쇄·복사 제한을 해제합니다.

        열기 비밀번호가 있는 PDF는 올바른 비밀번호가 필요합니다. 입력한 비밀번호를 모든 파일에 적용합니다. 한 파일은 PDF로, 여러 파일은 ZIP으로 저장하며 실패한 파일은 별도로 안내합니다. 파일과 비밀번호는 서버로 전송되지 않습니다.

          PDF 압축

          원본 유지 최적화 또는 이미지 압축으로 용량을 줄이세요.

          PDF

          압축할 PDF를 선택하세요

          문서 구조 최적화 또는 이미지 기반 강한 압축을 선택할 수 있습니다.

          강한 압축은 페이지를 이미지로 다시 저장하므로 텍스트 선택과 검색이 제한될 수 있습니다. 화질이 중요하면 해상도는 선명, 품질은 80% 이상을 사용하세요.
